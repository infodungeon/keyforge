# ADR-017: Orchestration Consolidation (Triad Merging)

* **Status:** Accepted
* **Date:** 2026-01-22
* **Context:** The system had extreme overlapping responsibilities across three crates: `keyforge-core` (glue), `keyforge-compute` (runtimes), and `keyforge-runner` (optimization wrappers). This resulted in triple-implementation of orchestration logic and inconsistent SessionBuilder patterns.
* **Decision:** Merge `keyforge-core` and `keyforge-runner` into `keyforge-compute`. Establish `compute` as the single authoritative crate for "How to run a KeyForge job."
* **Consequences:**
  * (+) Reduced maintenance surface area.
  * (+) Unified `SessionBuilder` and asset loading logic.
  * (+) Eliminated "Structural Duplication" technical debt.
  * (-) `keyforge-compute` now has a larger public API.
