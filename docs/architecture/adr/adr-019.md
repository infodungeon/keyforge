# ADR-019: Reified Actions (Hive Command Pattern)

* **Status:** Accepted
* **Date:** 2026-01-22
* **Context:** Hive business logic (registration, submission, cancellation) was coupled to Axum HTTP handlers. This made it difficult to test logic without a server and violated the "Intent vs Execution" separation.
* **Decision:** Introduce a `HiveCommand` enum and a reified `handle_command` logic block.
* **Consequences:**
  * (+) Business logic is decoupled from IO/Transport layers.
  * (+) Enables testing the "Functional Core" of Hive without Axum boilerplate.
  * (+) Unified error handling and auditing at the command dispatcher level.
  * (-) Adds a small layer of re-wrapping for simple CRUD actions.
