# Welcome to Keyforge

Keyforge is a high-performance, data-driven framework for keyboard layout analysis and optimization.

## Core Features

- **Physics-Based Scoring**: Accurately model finger movement and effort.
- **Distributed Optimization**: Utilize a cluster of agents to search for the perfect layout.
- **Cross-Platform UI**: Visualize and test layouts in a modern desktop application.
- **Flexible CLI**: Integrate Keyforge into your own workflows.
