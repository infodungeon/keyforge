    Operation Ironclad: KeyForge Master Execution Plan (v8.0)

    Status: Definitive Objective: Transform KeyForge from a functional prototype into a world-class, production-grade Distributed Genetic Optimization System. Architect: KeyForge Core

    PHASE 1: FOUNDATION & HYGIENE (The Cleanup)

    Goal: Fix architectural violations, race conditions, and ensure the application boots reliably on a fresh machine. Zero Silent Failures.

    ID Task Persona Description
    1.1 Unify I/O Logic (The Split Brain) ALEX Move ui/src-tauri/src/sync_engine.rs logic into crates/keyforge-workspace. Crucial: Implement RwLock on SessionState to prevent cmd_sync_data writing while Scorer reads.
    1.2 Native Asset Bootstrapper ELIAS Implement download_essentials() in keyforge-workspace. UI must trigger this on startup if data/ is missing to prevent crash-on-launch.
    1.3 Golden Master Regression Suite MORGAN Create a test set of 100 layouts with known scores. Verify "Poison Pill" penalties are clamped (e.g., 1M instead of 1B) to prevent integer overflow.
    1.4 Remove Silent Failures (Test Suite) MORGAN Modify: crates/keyforge-core/tests/system/parity.rs -> Replace early returns with panic!. Modify: crates/keyforge-core/tests/system/data_integrity.rs -> Add count tracking and assertions to ensure loop actually ran.
    1.5 Embedded Constants Audit VIKTOR Scan codebase for hardcoded paths (/usr/local/...) or magic numbers. Move them to Config structs or const definitions.
    1.6 Dependency Audit VIKTOR Remove reqwest from keyforge-ui. Purge --secret CLI args in favor of HIVE_SECRET env vars. Enforce "Protocol only imports types" rule.
    1.7 Phase 1 Acceptance MORGAN cargo check --workspace passes. UI boots on fresh machine without manual scripts. Regression suite passes.

    PHASE 2: DATA INTEGRITY & OPS (The Spine)

    Goal: Protect user data and ensure the server can evolve without wiping the database.

    ID Task Persona Description
    2.1 SQLx Migrations & JSONB MARCUS Replace schema.sql with versioned sqlx migrate files. Refactor scoring_profiles to use a JSONB column for weights to allow dynamic physics updates without schema changes.
    2.2 CI/CD Pipeline MARCUS Set up GitHub Actions for cargo test, clippy, and npm run build. Ensure no broken code merges to main.
    2.3 Agent Circuit Breaker ALEX Implement logic in keyforge-agent to track failure counts per Job ID. Blacklist Job if it causes >3 panics/errors.
    2.4 Input Sanitization Layer MARCUS Implement validate() trait in keyforge-protocol. Reject loader_trigram_limit > 50,000 and malformed geometry to prevent Node OOMs.
    2.5 API Rate Limiting MARCUS Add tower-governor middleware to keyforge-hive to prevent DoS via the /jobs and /results endpoints.

    PHASE 3: THE ENGINE ROOM (Performance & Personalization)

    Goal: Maximize optimization efficiency and enable user-specific customization.

    ID Task Persona Description
    3.1 Unified Statistics (Rust Port) ALEX Port statistical math from TS (ui/services/stats.ts) to Rust (keyforge-core). Expose cmd_get_layout_stats. Prerequisite for 3.2.
    3.2 Cost Matrix Generator SOLON Create command to read user_stats.json and generate personal_cost.csv. Allows optimizer to design for specific user finger speeds.
    we are here ===> 3.3 Scorer LRU Cache SOLON Implement Arc<Scorer> caching in Agent based on config hash. Prevent rebuilding lookup tables for every job in a batch.
    3.4 Zero-Allocation Parsing ALEX Refactor layout_string_to_u16 to write to a pre-allocated &mut [u16] buffer instead of returning Vec.
    3.5 Implement CompactPosMap SOLON Replace Box<[u8; 65536]> with [u8; 256] in the hot scoring loop to fit in L1 Cache.
    3.6 SIMD Safety Implementation ALEX Flesh out evolve_batch_avx2. Critical: Remove unwrap() calls inside hot paths to prevent panics on misaligned data.
    3.7 Fuzz Testing Core Parser MORGAN Run cargo-fuzz against the Scorer and Layout Parser to ensure the new Zero-Alloc/SIMD logic is memory safe.

    PHASE 4: THE HIVE MIND (Operations)

    Goal: Operational maturity and ecosystem health.

    ID Task Persona Description
    4.1 Job Lifecycle Manager MARCUS Add expires_at to DB. Implement background task in Hive to cull zombie jobs.
    4.2 Distributed Tracing MARCUS Add trace_id to Protocol. Pass UUID from UI -> Hive -> Agent -> Logs. Enable debugging of distributed failures.
    4.3 Log Management MARCUS Implement structured logging (JSON) for Hive and Agent. Ensure logs rotate and do not consume infinite disk space.

    PHASE 5: THE INTERFACE (UX & Polish)

    Goal: Make the tool usable by non-engineers. Fix broken features.

    ID Task Persona Description
    5.1 CRUD Operations ELIAS Implement full Create/Read/Update/Delete for Keyboards, Layouts, and Corpora in the UI.
    5.2 Corpus Manager UI ELIAS Drag-and-drop UI to ingest .txt files into custom N-gram profiles (e.g., "Coding", "Academic").
    5.3 Fix Import/Export VIKTOR Repair broken JSON import/export. Ensure it validates schema versioning.
    5.4 Fix Compare UI ELIAS The "Compare" button currently does nothing. Implement side-by-side Diff View (Heatmap Delta).
    5.5 WebSocket Purity ELIAS Refactor ui/src/App.tsx to stop polling GET /queue. Listen for WS JOB_UPDATE events for real-time feedback.
    5.6 Optimistic UI Pattern ELIAS Implement local state prediction in React to prevent "Jitter" while waiting for Rust backend calculations.
    5.7 Integrated Help (MkDocs) ELIAS Embed the documentation site (or a lightweight version) directly into the app via a Help overlay.

    PHASE 6: LAUNCH READINESS (Distribution)

    Goal: Distribution, lifecycle management, and final audit.

    ID Task Persona Description
    6.1 Installer & Auto-Update MARCUS Configure tauri.conf.json for updates. Build installers (.msi, .dmg, .deb).
    6.2 AppImage Fix MARCUS Fix Linux packaging issues. Ensure shared libraries are bundled correctly.
    6.3 Onboarding Flow ELIAS Create a "Welcome" modal sequence that guides the user to load a keyboard and run their first analysis.
    6.4 Arena Feedback Loop ELIAS Expose mostNeeded bigrams in the Arena UI so users understand why they are typing specific words.
    6.5 Final System Audit MORGAN Full regression pass. Documentation generation. Binary signing.
